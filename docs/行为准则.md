# 行为准则

> English: [Code of Conduct](../CODE_OF_CONDUCT.md)

## 参与项目

BangumiToday 欢迎不同背景和经验水平的用户与贡献者。参与者应免受骚扰与歧视，
不因年龄、身体条件、民族、性别、国籍、相貌、宗教或性取向等受到区别对待。

在 Issue、Discussion、Pull Request 和代码审查中，请：

- 围绕问题和证据友善交流；可以批评方案和代码，不要攻击提出它们的人。
- 提供有用的上下文，接受建设性反馈，对自己的错误负责，并帮助新人了解项目。
- 尊重他人的时间。本项目由个人维护，提出需求不意味着一定会实现、合并，
  或在固定时限内得到回复。
- 保持讨论与项目相关，保护他人的个人信息、凭据和私人订阅链接。

不接受骚扰、威胁、歧视性言论、不受欢迎的性相关内容或示好、泄露隐私、垃圾信息、
故意扰乱讨论，以及在被要求停止后持续施压。正常的技术分歧和善意的问题反馈受到欢迎。

## 适用范围

本准则适用于仓库的 Issue、Discussion、Pull Request、代码审查及其他由项目管理的
交流空间，也适用于被明确指定为项目代表的人在公开场合代表项目时的行为。
仅仅使用本应用，不代表成为项目代表。

## 报告与处理

如遇不当行为，请私下发送邮件至维护者 [BTMuli](mailto:bt-muli@outlook.com)：
**bt-muli@outlook.com**。请提供相关链接、事件背景和希望使用的联系方式。
不要在公开 Issue 中发布私人证据或个人信息；安全漏洞请按[安全策略](../SECURITY.md)报告。

维护者会根据现有证据评估，必要时向相关参与者补充询问。
报告内容和身份信息仅在调查、处理所必需的范围内共享，不承诺固定响应时限。

视严重程度和重复发生情况，处理方式可包括要求修改内容、警告、移除内容、锁定讨论，
或暂时、永久限制参与。严重威胁或骚扰可直接导致参与限制。适合说明时，维护者会在
不暴露私人信息的前提下解释决定。

如果认为处理决定遗漏了相关事实，可通过同一邮箱私下补充说明。
不要通过公开争执或反复联系向报告者及其他参与者施压。
